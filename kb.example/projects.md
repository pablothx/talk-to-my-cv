## tinyledger

Maintains tinyledger, an open-source double-entry bookkeeping library for the
JVM. It has 1,312 stars on GitHub and is used by two neobanks in Brazil.

## Conference talks

Spoke at a regional Java conference in 2023 with the talk "Your ledger is a
stream", about modelling accounting entries as events.
