## Backend Developer

Built the order and checkout services of an e-commerce marketplace with Java,
Spring Boot and PostgreSQL.

### Hackathon

Won BrightCart's internal "Golden Pigeon" hackathon award in 2019 with
Breadcrumb, a tool that traces a single order across eleven microservices.

### Database work

Migrated the orders database from MySQL to PostgreSQL with zero downtime, using
dual writes and a two-week shadow-read period.
