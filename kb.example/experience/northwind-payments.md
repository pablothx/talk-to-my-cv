## Senior Backend Engineer

Owns the settlement platform that moves merchant payouts across four countries.
Leads a team of five engineers.

### Project Lumen

Led Project Lumen, a ledger reconciliation engine written in Java 21. It cut the
nightly reconciliation run from 9 hours to 14 minutes by replacing batch SQL with
Kafka Streams.

### Infrastructure

Services run on AWS ECS Fargate, provisioned with AWS CDK. She has never used
Kubernetes in production: the team evaluated EKS in 2022 and chose ECS to keep
operations simple.

### Integrations

Integrated the billing service with HubSpot so that account managers see every
invoice and payout next to the merchant's account.
